# Clarence Ruwizhi — Personal Portfolio

A multidisciplinary creative portfolio showcasing work across graphic design, branding, web development, photography, video, product design and print production.

## 🎨 Built With

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Grid, Flexbox
- **Vanilla JavaScript** — No frameworks, no dependencies
- **Google Fonts** — Inter + Playfair Display

## 🎯 Features

- Fully responsive (desktop, tablet, mobile)
- Accessible (WCAG 2.1 AA compliant, keyboard navigation, reduced motion support)
- Fast loading (no frameworks, optimized assets)
- SEO ready (meta tags, Open Graph, semantic HTML)
- Portfolio filter system
- Lightbox gallery
- Contact form (Formspree integration)
- Print-friendly CV page
- 404 error page

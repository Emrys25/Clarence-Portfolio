# Clarence.R — Portfolio

Personal portfolio for Clarence Emrys Lion, a developer and designer based in Stellenbosch, South Africa.

## Tech

- Vanilla HTML, CSS, JavaScript
- No frameworks, no build step, no dependencies
- Component injection via JS fetch (header/footer)
- Client-side PDF generation for CV (html2pdf.js)
- Contact form via FormSubmit

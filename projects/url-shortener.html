URL Shortener Service

High-throughput redirection engine designed for sub-10ms latency using Node.js, Redis caching, Base62 hash generation, and PostgreSQL for long-term analytics storage.

System Concept

The URL Shortener Service is structured around a classic read-heavy architecture. Since short links are created once and read millions of times, the system prioritizes aggressive caching at the edge and memory layer before querying persistent storage.

Each long URL is converted into a 6-character Base62 string derived from an auto-incrementing unique sequence ID, yielding over 56 billion possible unique short combinations without collision risk.

Target System Flow

Key Architectural Pillars

  • Base62 Encoding: Replaces non-deterministic hashing with deterministic Base62 encoding over a distributed counter for collision-free short key generation.
  • Redis Caching Layer: Memory cache stores active keys with TTLs to serve 301/302 redirects directly from RAM without touching the database.
  • Asynchronous Analytics: Click metadata (referrer, country, timestamp) offloaded to an event queue to prevent blocking the HTTP response cycle.
  • PostgreSQL Storage: Relational schema for storing tenant accounts, original URLs, expiration policies, and aggregated daily analytics.

Code Concept: Base62 Encoder

Below is the core encoding utility planned for converting numeric database IDs into compact short codes:

TypeScript src/utils/base62.ts 
const ALPHABET = '0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ';
const BASE = ALPHABET.length;

export function encodeBase62(num: number): string {
  if (num === 0) return ALPHABET[0];
  
  let encoded = '';
  while (num > 0) {
    const remainder = num % BASE;
    encoded = ALPHABET[remainder] + encoded;
    num = Math.floor(num / BASE);
  }
  
  return encoded;
}

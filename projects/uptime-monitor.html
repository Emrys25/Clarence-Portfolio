Uptime & Health Monitor

Lightweight, background worker service that periodically polls target HTTP endpoints, tracks response latency, detects downtime, and dispatches immediate notification alerts via Discord webhooks.

Role Sole Developer
Target Stack Node.js, Express, node-cron, Axios
Alert Targets Discord Webhooks, Email
Status Planned / Concept

System Concept

Self-hosted uptime monitoring removes reliance on expensive third-party subscriptions. The Uptime & Health Monitor tracks website endpoints, internal APIs, and database health endpoints at configurable interval frequencies.

When a service returns a non-2xx status code or times out beyond strict SLA thresholds, the monitor state machine triggers alerting notifications without generating duplicate spam alerts during prolonged outages.

Target System Architecture

Key Architectural Features

  • Cron Polling Engine: Concurrent async workers running on node-cron scheduling schedules without blocking main HTTP event loops.
  • State Machine & Alert Cooldowns: Tracks status transition (UP to DOWN, DOWN to UP) to ensure notifications are dispatched only on state changes.
  • Discord Webhook Formatting: Rich embed alert notifications displaying response code, precise latency in milliseconds, and failure timestamp.
  • Latency Historical Logs: Lightweight timeseries logging storing latency averages to compute 24-hour SLA availability percentages.

Code Concept: Health Check Worker

Below is the core polling and notification dispatch mechanism planned for the worker loop:

TypeScript src/services/monitor.worker.ts 
import axios from 'axios';

interface TargetEndpoint {
  id: string;
  url: string;
  timeoutMs: number;
  lastStatus: 'UP' | 'DOWN';
}

export async function checkEndpointHealth(target: TargetEndpoint) {
  const startTime = Date.now();
  
  try {
    const response = await axios.get(target.url, { timeout: target.timeoutMs });
    const latency = Date.now() - startTime;
    
    if (target.lastStatus === 'DOWN') {
      await sendDiscordAlert(target, 'RECOVERED', response.status, latency);
      target.lastStatus = 'UP';
    }
  } catch (error: any) {
    const latency = Date.now() - startTime;
    const statusCode = error.response ? error.response.status : 500;
    
    if (target.lastStatus === 'UP') {
      await sendDiscordAlert(target, 'DOWN', statusCode, latency);
      target.lastStatus = 'DOWN';
    }
  }
}

Invoice Generator Engine

Lightweight document compilation utility that accepts structured JSON order data, calculates itemized totals and regional VAT taxes, and renders pixel-perfect PDF invoices in milliseconds.

Role Sole Developer
Target Stack Node.js, TypeScript, PDFKit, Handlebars
Output Format Standard A4 / Vector PDF
Status Planned / Concept

System Concept

Freelancers and small businesses frequently require clean, automated invoice generation without manual design or high-cost accounting software integrations.

The Invoice & Estimate Generator Engine combines HTML/CSS template compilation with streaming PDF rendering engines to produce lightweight, print-ready documents that can be downloaded locally or dispatched automatically via email attachment queues.

Target System Architecture

Key Architectural Features

  • Schema Validation: Strict TypeScript interfaces validating currency, client metadata, line item quantities, and discount rates before compilation.
  • Tax & Currency Calculator: Precision decimal arithmetic computing subtotal, localized VAT/tax percentage rates, and grand totals without floating point errors.
  • Dynamic Template Engine: Custom brand styling over Handlebars HTML templates compiled straight to high-resolution vector PDF streams.
  • Client & Server Modes: Runs server-side in Node.js pipelines or client-side via Web API Blob rendering.

Code Concept: Precision Calculation Logic

Below is the core calculation model designed to compute line item subtotals, VAT rates, and grand total structures accurately:

TypeScript src/services/invoice.calculator.ts 
export interface LineItem {
  description: string;
  quantity: number;
  unitPrice: number;
}

export interface InvoiceTotals {
  subtotal: number;
  taxAmount: number;
  grandTotal: number;
}

export function calculateInvoiceTotals(
  items: LineItem[], 
  taxRatePercent: number = 15
): InvoiceTotals {
  const subtotal = items.reduce((acc, item) => {
    return acc + (item.quantity * item.unitPrice);
  }, 0);

  const taxAmount = Math.round((subtotal * (taxRatePercent / 100)) * 100) / 100;
  const grandTotal = subtotal + taxAmount;

  return {
    subtotal: Math.round(subtotal * 100) / 100,
    taxAmount,
    grandTotal: Math.round(grandTotal * 100) / 100
  };
}

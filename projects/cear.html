Project Overview

Cear is built to solve a specific pain point in localized booking workflows: existing off-the-shelf SaaS solutions often enforce rigid payment gateways with high regional fees and offer weak support for dynamic multi-tenant isolation.

The goal of Cear is to provide service businesses with a zero-friction, lightning-fast booking engine that allows individual tenant custom branding, automated calendar synchronization, and native integration with localized payment providers like Paystack.

System Architecture & Technical Decisions

The platform is architected around strict tenant data isolation, sub-second API response rates, and robust webhooks for asynchronous payment fulfillment.

Core Architecture Highlights

  • Multi-Tenancy Layer: Domain and dynamic path-based routing, isolating client data via tenant identifiers embedded in token payloads and database query scopes.
  • Payment Processing: Native integration with Paystack API for localized split payments, automated webhooks validation, and transaction reconciliation.
  • State & Reservation Lock: Concurrency management preventing double-booking during active checkout sessions using short-lived database locks.
  • Type Safety: Full end-to-end type safety with TypeScript, sharing schema definitions between server endpoints and front-end forms.

Code Preview: Webhook Verification Pattern

A core requirement of payment integrations is robust cryptographic signature validation before fulfilling transactions. Below is a representation of the webhook handler logic:

TypeScript src/webhooks/paystack.handler.ts 
import { createHmac } from 'crypto';
import { Request, Response } from 'express';

export const verifyPaystackSignature = (req: Request, res: Response) => {
  const secret = process.env.PAYSTACK_SECRET_KEY!;
  const hash = createHmac('sha512', secret)
    .update(JSON.stringify(req.body))
    .digest('hex');

  if (hash !== req.headers['x-paystack-signature']) {
    return res.status(401).json({ status: 'unauthorized' });
  }

  const { event, data } = req.body;
  if (event === 'charge.success') {
    // Process tenant booking fulfillment asynchronously
    await fulfillReservation(data.reference);
  }

  return res.status(200).send({ status: 'success' });
};

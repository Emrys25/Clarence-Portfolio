System Concept

Building AI-powered utilities requires moving away from slow, blocking JSON HTTP responses toward chunked response streaming. Users expect immediate typewriter-style feedback as tokens are generated.

The AI Tool Integrator serves as a modular API middleware wrapper around OpenAI and open-source models, handling system prompt injection, user input sanitization, dynamic context assembly, and real-time streaming over FastAPI event generators.

Target System Architecture

Key Architectural Features

  • FastAPI Async Processing: Asynchronous event loop capable of handling high concurrent connection volumes during long-lived generation streams.
  • Server-Sent Token Delivery: Yields LLM completion tokens immediately to web client interfaces via Server-Sent Events (SSE).
  • Prompt Template Versioning: Server-side prompt templates separated from client code to prevent reverse engineering or prompt exposure.
  • Usage Ledger & Rate Limiting: Tracks prompt/completion token counts per API key to enforce rate limits and billable usage tiers.

Code Concept: FastAPI Token Streaming Generator

Below is the core Python endpoint pattern for handling async streaming completions from the OpenAI API:

Python app/routers/completion.py 
from fastapi import FastAPI, HTTPException
from fastapi.responses import StreamingResponse
import openai
import async_timeout

app = FastAPI()

async def stream_llm_completion(prompt_text: str):
    try:
        response = await openai.ChatCompletion.acreate(
            model="gpt-4",
            messages=[
                {"role": "system", "content": "You are an expert technical assistant."},
                {"role": "user", "content": prompt_text}
            ],
            stream=True
        )
        async for chunk in response:
            content = chunk["choices"][0]["delta"].get("content", "")
            if content:
                yield f"data: {content}\n\n"
    except Exception as e:
        yield f"data: [ERROR: {str(e)}]\n\n"

@app.post("/api/generate")
async def generate_ai_response(prompt: str):
    return StreamingResponse(
        stream_llm_completion(prompt),
        media_type="text/event-stream"
    )

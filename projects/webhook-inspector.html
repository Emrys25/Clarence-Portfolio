Webhook Inspector & Debugger

Developer utility for capturing, inspecting, validating cryptographic signatures, and replaying inbound HTTP webhooks in real time via Server-Sent Events (SSE).

System Concept

Developing third-party integrations (Paystack, Stripe, GitHub, Shopify) locally can be tedious without dedicated tools to inspect incoming raw request bodies and headers.

Webhook Inspector generates temporary unique endpoint URLs that stream incoming HTTP payloads directly to a connected browser dashboard in real time without requiring page refreshes.

Target System Architecture

Key Technical Capabilities

  • Raw Body Preservation: Preserves exact byte streams before JSON parsing to allow accurate cryptographic HMAC signature verification.
  • Server-Sent Events (SSE): Lightweight, unidirectional streaming channel pushing incoming payloads to front-end clients instantly.
  • Payload Replay Engine: Ability to re-send captured HTTP requests to local localhost development servers with identical headers.
  • Ephemeral Sessions: Auto-expiring bucket URLs backed by TTL keys in memory to minimize storage waste.

Code Concept: SSE Stream Broadcasting

Below is an Express endpoint pattern for accepting webhooks and broadcasting payload events to open SSE client connections:

TypeScript src/routes/webhook.stream.ts 
import { Request, Response } from 'express';

const clients = new Set<Response>();

// SSE Client Connection Endpoint
export const handleSSEConnect = (req: Request, res: Response) => {
  res.setHeader('Content-Type', 'text/event-stream');
  res.setHeader('Cache-Control', 'no-cache');
  res.setHeader('Connection', 'keep-alive');

  clients.add(res);
  req.on('close', () => clients.delete(res));
};

// Inbound Webhook Listener
export const handleInboundWebhook = (req: Request, res: Response) => {
  const payload = {
    timestamp: new Date().toISOString(),
    headers: req.headers,
    body: req.body
  };

  for (const client of clients) {
    client.write(`data: ${JSON.stringify(payload)}\n\n`);
  }

  res.status(200).json({ status: 'received' });
};
